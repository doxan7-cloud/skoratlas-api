# SkorAtlas API

SkorAtlas mobil uygulaması için yasal futbol fikstürü ve canlı skor ara sunucusu.

## Render kurulumu

- Build Command: `npm ci --omit=dev`
- Start Command: `npm start`
- Health Check Path: `/health`
- Environment Variable: `API_FOOTBALL_KEY`

API anahtarını dosyalara yazmayın. Render üzerindeki Environment bölümünde gizli değişken olarak ekleyin.
